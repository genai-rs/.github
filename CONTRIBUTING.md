# Contributing to genai-rs

Start with the target repository's contribution guide and applicable `AGENTS.md`
files. Keep each change small, reproducible, and scoped to one task and one pull
request. Use offline tests or local mocks for routine validation.

The [agent task delivery contract](docs/agent-task-contract.md) provides a copyable
template and a workflow for claims, focused validation, review, and Kata evidence.
Repositories can opt in through their own contribution guide or `AGENTS.md`, as
explained in the contract. This organization document is not automatically
inherited as an `AGENTS.md` instruction file by other repositories.

Submitting an implementation or opening a PR does not grant merge or release
authority. Maintainers or explicitly authorized reviewers accept changes; package
publication and repository settings require their own authorization.
